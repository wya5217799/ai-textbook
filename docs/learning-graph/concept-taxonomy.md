# Concept Taxonomy

The following taxonomy organizes the 200 concepts into 12 categories for visualization and navigation.

## Categories

### 1. Foundation Concepts (FOUND)

**TaxonomyID:** FOUND

Core AI/ML definitions, historical context, and the high-level types of machine learning. These are entry-point concepts that orient the student.

### 2. Programming Tools (TOOL)

**TaxonomyID:** TOOL

Python ecosystem, libraries, and development environment concepts used throughout the course.

### 3. Data Acquisition (DACQ)

**TaxonomyID:** DACQ

Concepts related to finding, collecting, integrating, and generating datasets for machine learning projects.

### 4. Data Preprocessing (DPRE)

**TaxonomyID:** DPRE

Data cleaning, error detection, normalization, feature engineering, and preparation of data for model training.

### 5. Linear Algebra and Math (MATH)

**TaxonomyID:** MATH

Mathematical foundations including matrix operations, probability distributions, and statistical concepts underpinning ML algorithms.

### 6. Linear Regression (LREG)

**TaxonomyID:** LREG

Linear regression model, objective functions, loss functions, and the normal equation closed-form solution.

### 7. Optimization (OPTM)

**TaxonomyID:** OPTM

Gradient descent variants, learning rate, convergence, parameter updates, and general optimization concepts.

### 8. Model Evaluation (EVAL)

**TaxonomyID:** EVAL

Regression and classification evaluation metrics, confusion matrix components, ROC/AUC, and model selection criteria.

### 9. Classification (CLSF)

**TaxonomyID:** CLSF

Logistic regression, sigmoid/softmax functions, binary and multi-class classification, KNN algorithm, and decision boundaries.

### 10. Clustering (CLST)

**TaxonomyID:** CLST

Unsupervised clustering algorithms including K-Means, DBSCAN, and their components such as centroids, density concepts, and parameter selection.

### 11. Neural Networks (NEUR)

**TaxonomyID:** NEUR

Perceptron, activation functions, fully connected networks, forward pass, backpropagation, and training loop concepts.

### 12. Deep Learning Architectures (DEEP)

**TaxonomyID:** DEEP

CNN layers and operations, RNN/LSTM, advanced architectures, model deployment, and the complete ML workflow.
