# H63AIS 人工智能系统学习图谱

本节包含本教材的学习图谱（learning graph）。学习图谱是本教材所用概念构成的有向图，每个概念对应图中的一个节点，节点之间通过有向边相连，表示理解某一概念之前必须先掌握哪些前置概念。

学习图谱是智能教材的核心数据结构，能够为学生推荐学习路径，就像一张指引学生到达学习目标的概念路线图。

图谱左侧是基础概念（prerequisite / foundational concept），它们没有出边，只有其他概念指向它们的入边。图谱右侧是课程中最进阶的概念——要掌握这些概念，必须先理解它们所指向的所有前置概念。

以下是学习图谱相关的其他文件。

## 课程简介

我们以[课程简介](../course-description.md)作为确定本课程概念范围的源文档。课程简介采用 2001 年 Bloom 分类法对学习目标进行排序。

## 概念列表

我们使用 generative AI 将课程简介转化为[概念列表](./concept-list.md)。每个概念均以简短的 Title Case 标签呈现，大多数标签不超过 32 个字符。

## 概念依赖列表

我们进一步使用 generative AI 构建一个 Directed Acyclic Graph（DAG，有向无环图）。DAG 不含循环依赖，即概念不会依赖自身。DAG 提供两种格式：[CSV 文件](learning-graph.csv) 和使用 vis-network JavaScript 库格式的 [JSON 文件](learning-graph.json)。JSON 格式包含 `nodes`、`edges` 和 `metadata` 元素，边使用 `from` 和 `to` 属性，便于通过 vis-network 工具构建的编辑器进行查看和编辑。

### 概念分类体系

为了发现学习图谱中的规律，将每个概念按类型着色非常有用。我们使用 generative AI 为概念创建约 12 个类别，并将每个概念归入唯一的主类别。

- 包含 12 个类别的概念分类体系
- 类别组织——基础元素优先，课程收尾项目概念在后
- 类别分布均衡（各占 3.5%–14.5%）
- 所有类别均低于 30% 上限
- 教学流程建议
- 在 CSV 文件中使用的清晰 3–5 字母缩写
