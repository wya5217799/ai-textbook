# 参考文献：数据预处理与特征工程

1. [Feature engineering](https://en.wikipedia.org/wiki/Feature_engineering) - Wikipedia — 全面综述 feature engineering 技术，包括 feature selection、transformation 和创建新 feature 以提升 ML 模型性能。

2. [Normalization (statistics)](https://en.wikipedia.org/wiki/Normalization_(statistics)) - Wikipedia — 解释 normalization 和 standardization 方法的数学定义，涵盖 data preprocessing 中使用的 min-max scaling 和 z-score standardization。

3. [Missing data](https://en.wikipedia.org/wiki/Missing_data) - Wikipedia — 覆盖 missing data 的机制（MCAR、MAR、MNAR）、imputation 策略，以及 missing value 对 ML 模型训练的影响。

4. Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (3rd Edition) - Aurélien Géron - O'Reilly Media — 第 2 章提供完整的端到端项目，使用 scikit-learn 实现 data cleaning、feature scaling 和 transformation pipeline。

5. Feature Engineering for Machine Learning - Alice Zheng, Amanda Casari - O'Reilly Media — 专注 feature engineering 的参考书，涵盖 categorical variable encoding、missing value 处理和 feature selection 策略。

6. [Feature Scaling Techniques in Machine Learning](https://www.geeksforgeeks.org/ml-feature-scaling-part-2/) - GeeksforGeeks — 实践教程，涵盖 min-max scaling、standardization、robust scaling 和 normalization，附 scikit-learn Python 实现。

7. [Data Cleaning in Machine Learning](https://www.geeksforgeeks.org/ml-handling-missing-values/) - GeeksforGeeks — 讲解 data cleaning 核心步骤：检测和处理 missing value、outlier 和重复数据。

8. [Train/Test Split and Cross Validation in Python](https://www.geeksforgeeks.org/how-to-do-train-test-split-using-sklearn-in-python/) - GeeksforGeeks — 使用 scikit-learn 划分 training set 和 test set 的教程，涵盖 stratified split 和随机种子最佳实践。

9. [Outlier Detection](https://en.wikipedia.org/wiki/Anomaly_detection) - Wikipedia — 综述 outlier 和 anomaly detection 方法，包括用于识别错误数据点的统计方法和 ML 方法。

10. [Scikit-learn Preprocessing](https://scikit-learn.org/stable/modules/preprocessing.html) - Scikit-learn Official Docs — 官方参考文档，覆盖所有 preprocessing utility，包括 scaler、encoder 和 transformer，附直接适用于课程实验的代码示例。
