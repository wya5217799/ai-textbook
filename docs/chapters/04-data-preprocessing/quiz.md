# 测验：数据预处理与特征工程

通过以下题目测试你对数据清洗、特征工程和数据集划分的理解。

---

#### 1. 在 machine learning 数据集的语境中，什么是特征（feature）？

<div class="upper-alpha" markdown>
1. 模型被训练来预测的标签
2. 每个数据点的可测量属性，作为学习算法的输入
3. 用于评估训练模型的性能指标
4. 神经网络中检测模式的架构组件
</div>

??? question "显示答案"
    正确答案是 **B**。特征（feature，也称为属性、预测变量或自变量）是用作输入的数据点的可测量属性。对于房价预测任务，特征包括面积、卧室数量和所在街区。特征与标签（被预测的值）和评估指标不同。

    **考察概念：** Feature（特征）

---

#### 2. 一个数据集有500个样本，每个样本由20个测量值描述。特征矩阵 X 的形状是什么？

<div class="upper-alpha" markdown>
1. (20, 500) — 20行，500列
2. (500, 20) — 500行，20列
3. (500, 1) — 500行，单一特征列
4. (20, 1) — 20个特征存储为单个向量
</div>

??? question "显示答案"
    正确答案是 **B**。按照惯例，特征矩阵 X 的形状为（n_samples，n_features）。每行代表一个数据点（样本），每列代表一个特征。包含500个样本和20个特征的数据集，X 的形状为（500，20）。这一惯例在 NumPy、Pandas 和 Scikit-learn 中是一致的。

    **考察概念：** Feature Vector、Dimensionality

---

#### 3. 什么是"维度灾难"（curse of dimensionality），它对 machine learning 有何影响？

<div class="upper-alpha" markdown>
1. 高维模型训练太慢，因为每次梯度步骤需要更多计算
2. 随着特征数量增加，数据变得稀疏，距离失去意义，模型需要指数级更多的数据才能学习
3. 具有多层的神经网络难以初始化，导致梯度消失（vanishing gradients）
4. 大型数据集需要的内存超过单台机器的可用内存，导致数据加载变慢
</div>

??? question "显示答案"
    正确答案是 **B**。随着维度增加，特征空间的体积呈指数增长，使数据越来越稀疏。基于距离的算法会崩溃，因为所有点之间的距离变得大致相等。模型需要指数级更多的训练数据才能泛化。特征选择（feature selection）和降维（dimensionality reduction）是常见的解决方法。

    **考察概念：** Dimensionality

---

#### 4. 你会使用哪种技术来检测远超预期值范围的数据错误？

<div class="upper-alpha" markdown>
1. One-hot encoding
2. 异常值检测（Outlier detection）
3. 数据划分（Data splitting）
4. 数据归一化（Data normalization）
</div>

??? question "显示答案"
    正确答案是 **B**。Outlier detection 识别与预期分布有显著偏差的数据点。方法包括基于规则的检测（标记超出预定义范围的值）和基于模式的检测（使用统计模型识别异常）。检测到的异常值可能是需要更正或删除的错误。

    **考察概念：** Outlier Detection、数据错误

---

#### 5. 一个数据集的"年龄"列中有缺失值。以下哪项是对缺失值（missing value）的正确定义？

<div class="upper-alpha" markdown>
1. 在数据集中大多数样本其值为零的特征
2. 未记录的缺失或未定义的测量值
3. 在标注过程中被分配了错误类别的标签
4. 与目标变量没有相关性的特征列
</div>

??? question "显示答案"
    正确答案是 **B**。缺失值是未收集、在传输过程中丢失或由受访者留空的测量值。常见策略包括插补（imputation，用均值、中位数或预测值替换）或根据缺失的比例和模式删除受影响的行或列。

    **考察概念：** Missing Values

---

#### 6. 什么是数据归一化（data normalization），为什么它在训练许多 machine learning 算法之前很重要？

<div class="upper-alpha" markdown>
1. 随机打乱训练数据，防止算法学习样本的顺序
2. 将特征值缩放到一个共同范围，使没有单一特征因其测量尺度而占主导地位
3. 将分类标签转换为数值代码，以便在回归模型中使用
4. 删除携带与其他特征相同信息的冗余特征
</div>

??? question "显示答案"
    正确答案是 **B**。Data normalization 将特征缩放到共同范围（如0到1，或零均值/单位方差）。如果不进行归一化，以千为单位测量的特征（如收入）将主导以个位数测量的特征（如子女数量），导致梯度下降（gradient descent）和 KNN 等算法表现不佳。

    **考察概念：** Data Normalization

---

#### 7. 为什么测试集（test set）绝不能在模型训练或超参数调整期间使用？

<div class="upper-alpha" markdown>
1. 测试数据太小，无法对训练产生有意义的贡献
2. 在开发过程中使用测试数据会导致数据泄露（data leakage），产生过于乐观的性能估计，无法反映真实世界的泛化能力
3. 测试数据未经归一化，会给训练过程引入误差
4. 测试数据只包含负样本，会使模型偏向预测负类
</div>

??? question "显示答案"
    正确答案是 **B**。测试集必须在最终评估之前完全保持"未见过"的状态。如果在开发、模型选择或调整过程中使用了测试数据，最终报告的性能会乐观地存在偏差，因为模型间接"看到"了测试数据。这称为数据泄露（data leakage），会导致模型在实际部署中表现不佳。

    **考察概念：** Test Set、Data Splitting

---

#### 8. 验证集（validation set）在 machine learning 工作流中的作用是什么？

<div class="upper-alpha" markdown>
1. 在训练集太小时生成新的训练样本
2. 提供一个保留集，用于在开发过程中调整超参数和监测过拟合（overfitting）
3. 在所有开发完成后评估最终模型性能
4. 在训练期间存储最佳模型检查点（checkpoint），以便后续部署
</div>

??? question "显示答案"
    正确答案是 **B**。验证集在模型开发期间用于比较架构、选择超参数和检测 overfitting。与测试集不同，它可以在开发过程中多次使用。测试集保留用于单次最终评估。训练集用于更新模型参数。

    **考察概念：** Validation Set、Data Splitting

---

#### 9. 什么是特征选择（feature selection），它解决了什么问题？

<div class="upper-alpha" markdown>
1. 通过应用变换将原始输入转换为更具信息量的表示
2. 识别并保留最具信息量的特征，以降低维度并提高模型效率
3. 为颜色或品牌等分类特征值分配数值代码
4. 在训练前将特征值缩放到有界范围内
</div>

??? question "显示答案"
    正确答案是 **B**。Feature selection 识别最具信息量的特征子集并丢弃不相关或冗余的特征。这减少了维度，加快了训练速度，降低了 overfitting 风险，通常还能提高模型性能。方法包括过滤器方法（filter methods，统计检验）、包装器方法（wrapper methods，前向/后向选择）和嵌入方法（embedded methods，正则化）。

    **考察概念：** Feature Selection

---

#### 10. 一名学生对数据集进行探索性数据分析（EDA），发现某一特征有60%的缺失值。最合适的第一步行动是什么？

<div class="upper-alpha" markdown>
1. 立即训练模型；大多数算法会自动处理缺失值
2. 根据该特征的重要性和缺失模式，决定是插补缺失值、使用缺失指示符，还是删除该特征
3. 将所有缺失值替换为零，因为这是标准的预处理步骤
4. 在检查任何其他数据质量问题之前，先删除所有包含缺失值的行
</div>

??? question "显示答案"
    正确答案是 **B**。60%的缺失率是相当严重的。适当的行动取决于具体情况：如果该特征至关重要，插补或缺失指示符可以保留信息；如果缺失是随机的且该特征预测能力弱，删除它可能是最佳选择。简单地用零替换（C）或删除行（D）可能会引入系统性偏差或损失过多数据。

    **考察概念：** Missing Values、Exploratory Data Analysis、数据清洗
