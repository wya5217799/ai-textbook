# 测验：使用反向传播训练神经网络

通过以下题目测试你对前向传播、反向传播、权重更新、训练循环和 dropout 的理解。

---

#### 1. 神经网络中的前向传播（forward pass）是什么？

<div class="upper-alpha" markdown>
1. 通过向后传播误差来计算梯度的过程
2. 通过将输入数据从输入层到输出层逐层传递来计算预测的过程
3. 训练开始前使用随机分布初始化权重的过程
4. 在训练前从输入中选择最相关特征的过程
</div>

??? question "显示答案"
    正确答案是 **B**。前向传播（forward pass）通过将输入数据依次传递到每一层来计算网络的预测：x → 第1层 → 第2层 → ... → 输出层。在每一层，应用线性变换 z = Wa + b，然后应用激活函数 a = g(z)。最终输出是用于计算损失的预测 ŷ。

    **考察概念：** Forward Pass

---

#### 2. 什么是反向传播（backpropagation），它应用了什么数学原理？

<div class="upper-alpha" markdown>
1. 一种通过从输出层到输入层传播随机值来初始化网络权重的算法
2. 一种通过从输出层到输入层应用链式法则（chain rule）来计算损失对所有参数梯度的算法
3. 一种通过比较输出层预测与随机打乱的标签来更新权重的方法
4. 一种通过向后传播激活分数来选择保留哪些神经元的技术
</div>

??? question "显示答案"
    正确答案是 **B**。反向传播（backpropagation）通过从输出层向输入层递归应用链式法则，高效计算损失函数对网络中每个权重和偏置的梯度。每一层从其上方的层接收误差信号，并将修改后的信号传播到下方的层，使梯度下降（gradient descent）能够更新所有参数。

    **考察概念：** Backpropagation、Chain Rule

---

#### 3. 反向传播中的误差信号（error signal）是什么？

<div class="upper-alpha" markdown>
1. 输出层预测的类别概率与真实类别标签之间的差
2. 向后传播到每一层的值，表示该层的计算对整体损失的贡献程度
3. 学习率相对于训练 epoch 总数的梯度
4. 神经元激活在前向传播期间超过触发阈值的量
</div>

??? question "显示答案"
    正确答案是 **B**。在反向传播期间，为每一层计算误差信号（delta，δ）。输出层误差信号 δ^[L] 衡量输出与目标的偏差程度。该信号向后传播：每个隐藏层的误差信号由下一层的误差信号乘以连接权重得到。这些信号使得能够计算每个参数的损失梯度。

    **考察概念：** Error Signal

---

#### 4. 反向传播中的权重更新规则（weight update rule）实现了什么？

<div class="upper-alpha" markdown>
1. 它随机重新初始化训练期间变得过大的权重
2. 它沿负梯度方向调整每个权重，以减少损失
3. 它在迁移学习（transfer learning）中选择哪些权重冻结，哪些继续训练
4. 它将权重值裁剪到预定义范围以防止数值溢出
</div>

??? question "显示答案"
    正确答案是 **B**。权重更新规则 W := W - α × ∂L/∂W 沿负梯度方向调整每个权重。反向传播计算所有权重的 ∂L/∂W；然后梯度下降应用更新。这个迭代过程将所有权重移向最小化训练损失的值。

    **考察概念：** Weight Update

---

#### 5. 什么是一个训练 epoch？

<div class="upper-alpha" markdown>
1. 对一个训练样本的单次前向传播
2. 对整个训练数据集的一次完整遍历
3. 梯度下降参数更新的一次迭代
4. 损失减少预定义阈值所需的时间
</div>

??? question "显示答案"
    正确答案是 **B**。Epoch 是对整个训练数据集的一次完整遍历。对于批大小为 b、有 n 个训练样本的 mini-batch 梯度下降，一个 epoch 由 n/b 次权重更新组成。训练收敛需要多个 epoch。每个 epoch 监控训练和验证损失有助于诊断 overfitting 并确定何时停止。

    **考察概念：** Epoch

---

#### 6. 什么是训练循环（training loop），它每个 epoch 重复哪些操作？

<div class="upper-alpha" markdown>
1. 一个软件循环，重复查询 Web API 以下载新的训练数据
2. 一个迭代过程，反复执行前向传播、损失计算、反向传播和权重更新
3. 一个检查验证损失是否改善并在未改善时回滚权重的循环
4. 一个在训练前循环遍历不同学习率以找到最优值的算法
</div>

??? question "显示答案"
    正确答案是 **B**。训练循环是训练神经网络的核心过程。在每次迭代中，它：(1) 执行前向传播（forward pass）计算预测，(2) 计算损失，(3) 执行反向传播（backpropagation）计算梯度，(4) 应用权重更新规则。这个循环在多个 epoch 的许多迭代（mini-batch）中重复，直到模型收敛。

    **考察概念：** Training Loop

---

#### 7. Dropout 正则化在训练期间如何工作？

<div class="upper-alpha" markdown>
1. 它删除损失最高的训练样本，以专注于学习简单样本
2. 它在每次前向传播期间随机将一小部分神经元输出设置为零，迫使网络不依赖任何单个神经元
3. 它从输入中删除低方差特征以减少维度
4. 它在训练损失停止改善时按固定因子降低学习率
</div>

??? question "显示答案"
    正确答案是 **B**。Dropout 在训练期间每次前向和反向传播时随机停用（归零）一部分 p 的神经元。每次传播中被删除的神经元不同，因此网络无法依赖特定的神经元。这相当于训练许多不同子网络的集成，并产生更鲁棒、更具泛化能力的特征。在测试时，所有神经元都处于活动状态，但其输出会被缩放。

    **考察概念：** Dropout

#### 8. 为什么反向传播先计算输出层参数的梯度，然后再计算隐藏层参数的梯度？

<div class="upper-alpha" markdown>
1. 输出层权重幅度更大，必须先更新以稳定训练
2. 链式法则要求在将误差信号传播到早期层之前，先在输出层计算梯度
3. 隐藏层梯度可以通过解析方法计算，无需反向传播
4. 如果先计算隐藏层梯度，输出层梯度将始终为零
</div>

??? question "显示答案"
    正确答案是 **B**。反向传播递归地应用链式法则。损失相对于隐藏层 l 参数的梯度依赖于损失相对于第 l+1 层输入的梯度。因此，梯度必须从输出层（损失直接定义的地方）向后计算，经过每个隐藏层直到输入层。这就是该算法被称为"反向"传播的原因。

    **考察概念：** Backpropagation、Output Layer Error、Hidden Layer Error

---

#### 9. 反向传播中的偏置更新（bias update）遵循哪个规则？

<div class="upper-alpha" markdown>
1. 偏置在反向传播期间不更新；它们保持在初始化值
2. 每个偏置通过减去学习率乘以损失相对于该偏置的梯度来更新
3. 偏置每个 epoch 更新一次，通过对所有 mini-batch 的值取平均
4. 每次更新后，每个偏置被设置为同一层权重的负均值
</div>

??? question "显示答案"
    正确答案是 **B**。偏置更新遵循与权重更新相同的梯度下降规则：b := b - α × ∂L/∂b。反向传播计算损失相对于每个偏置的梯度（∂L/∂b = δ，该层的误差信号）。偏置是可训练参数，用于移动激活函数，并在每个训练步骤中更新。

    **考察概念：** Bias Update

---

#### 10. 一个训练了很多 epoch 的神经网络实现了接近零的训练损失，但验证性能很差。哪种训练修改最能直接解决这个问题？

<div class="upper-alpha" markdown>
1. 增加层数，给模型更多容量来学习复杂模式
2. 在训练期间应用 dropout，并根据验证损失使用 early stopping
3. 从所有层删除 bias term 以简化参数更新计算
4. 从 mini-batch 梯度下降切换到批量梯度下降以使用更稳定的梯度
</div>

??? question "显示答案"
    正确答案是 **B**。接近零的训练损失但验证性能差是典型的过拟合（overfitting）。Dropout 迫使网络学习冗余表示并防止神经元的协同适应，减少 overfitting。Early stopping 在最佳验证性能点停止训练，防止网络进一步过拟合。它们合在一起是主要的神经网络特定正则化工具。

    **考察概念：** Dropout、Training Loop、Epoch
