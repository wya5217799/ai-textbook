# 参考文献：神经网络基础

1. [Artificial neural network](https://en.wikipedia.org/wiki/Artificial_neural_network) - Wikipedia — 全面综述 neural network 架构，包括 neuron、layer、weight、bias、activation function 和 feedforward computation graph。

2. [Perceptron](https://en.wikipedia.org/wiki/Perceptron) - Wikipedia — 详细介绍 perceptron 模型的历史与数学描述，包括其学习规则及促使多层架构产生的局限性。

3. [Activation function](https://en.wikipedia.org/wiki/Activation_function) - Wikipedia — 涵盖所有主要 activation function 的参考资料，包括 sigmoid、tanh 和 ReLU 的数学定义、图像及性质分析。

4. Deep Learning (Adaptive Computation and Machine Learning Series) - Ian Goodfellow, Yoshua Bengio, Aaron Courville - MIT Press — 第 6–7 章介绍 feedforward network 架构、activation function 和 universal approximation theorem，是权威的 neural network 参考书。

5. Neural Networks and Deep Learning (free online book) - Michael Nielsen - Determination Press — 第 1 章以 MNIST 数字分类问题为例，从零开始建立 neural network 直觉；适合视觉化、示例驱动的学习者。

6. [Activation Functions in Neural Networks](https://www.geeksforgeeks.org/activation-functions-neural-networks/) - GeeksforGeeks — 可视化对比 sigmoid、tanh、ReLU 等 activation function，附代码示例和各层函数选择建议。

7. [Building a Neural Network with PyTorch](https://docs.pytorch.org/tutorials/beginner/basics/buildmodel_tutorial.html) - PyTorch Official Docs — 官方教程，介绍如何在 PyTorch 中构建 fully connected neural network，包括定义 layer、指定 activation function 和执行 forward pass。

8. [Introduction to Neural Networks](https://www.geeksforgeeks.org/introduction-to-artificial-neutral-networks/) - GeeksforGeeks — 通俗介绍生物 neuron 类比、perceptron 模型和多层 feedforward network，附图示和 Python 示例。

9. [Chain Rule in Calculus](https://www.geeksforgeeks.org/chain-rule-derivative/) - GeeksforGeeks — 清晰讲解 chain rule 作为 backpropagation 数学基础的原理，并通过复合函数微分示例加以说明。

10. [Scikit-learn Neural Network Documentation](https://scikit-learn.org/stable/modules/neural_networks_supervised.html) - Scikit-learn Official Docs — MLPClassifier 和 MLPRegressor 的官方文档，涵盖架构设定、activation function、训练算法和实际使用指南。
