# 测验：K 最近邻算法

通过以下题目测试你对 KNN 分类、距离度量和超参数调整的理解。

---

#### 1. K 最近邻（KNN，K-Nearest Neighbor）算法如何对新的查询点进行预测？

<div class="upper-alpha" markdown>
1. 它计算所有训练样本的加权和并应用 sigmoid 函数
2. 它找到距查询点最近的 K 个训练样本，并在它们中分配多数类
3. 它在训练期间学习决策边界，并根据这个边界评估查询点
4. 它使用训练集上的最大似然估计生成概率估计
</div>

??? question "显示答案"
    正确答案是 **B**。KNN 存储整个训练集。在预测时，它计算查询点到每个训练样本的距离，选择 K 个最近邻，并分配它们中最频繁的类别标签（多数投票）。训练期间没有参数学习——KNN 是一种"懒惰"学习器，将所有计算推迟到预测时。

    **考察概念：** K-Nearest Neighbor

---

#### 2. KNN 是"非参数方法"（nonparametric method）意味着什么？

<div class="upper-alpha" markdown>
1. KNN 不使用任何距离度量来比较数据点
2. KNN 不学习固定的参数集；它保留整个训练数据集用于预测
3. KNN 需要的超参数比逻辑回归等参数模型更少
4. KNN 对数据的底层概率分布不做任何假设
</div>

??? question "显示答案"
    正确答案是 **B**。非参数方法不将训练数据压缩为固定的参数集。KNN 存储所有训练样本并在预测时直接使用它们。模型的"大小"随训练数据增长。这与参数模型（逻辑回归、神经网络）形成对比，后者学习固定的参数集并在训练后丢弃训练数据。

    **考察概念：** Nonparametric Method

---

#### 3. d 维空间中两点 x 和 y 之间的欧几里得距离（Euclidean distance）是如何计算的？

<div class="upper-alpha" markdown>
1. Σᵢ|xᵢ - yᵢ| — 各维度绝对差之和
2. max(|xᵢ - yᵢ|) — 所有维度上的最大绝对差
3. √(Σᵢ(xᵢ - yᵢ)²) — 平方差之和的平方根
4. Σᵢ(xᵢ × yᵢ) / (||x|| × ||y||) — 向量的归一化点积
</div>

??? question "显示答案"
    正确答案是 **C**。欧几里得距离（L2 距离）是空间中两点之间的直线距离，计算为坐标差的平方和的平方根。选项 A 是 L1（曼哈顿，Manhattan）距离，选项 B 是切比雪夫（Chebyshev）距离，选项 D 是余弦相似度（cosine similarity，测量角度，而非距离）。

    **考察概念：** Euclidean Distance、Distance Metric

---

#### 4. L1 距离（曼哈顿距离，Manhattan distance）测量哪个量？

<div class="upper-alpha" markdown>
1. 欧几里得空间中两点之间的直线距离
2. 沿每个特征维度的绝对差之和
3. 任意单个维度上的最大绝对差
4. 两个特征向量之间夹角的余弦值
</div>

??? question "显示答案"
    正确答案是 **B**。L1 距离 = Σᵢ|xᵢ - yᵢ|。它沿每个轴的绝对差求和，类似于沿水平和垂直街道在城市网格中导航（因此称为"曼哈顿"距离）。与欧几里得距离不同，L1 不对差进行平方，因此对单个维度中的极值不那么敏感。

    **考察概念：** L1 Distance

---

#### 5. 在 KNN 分类中，"多数投票"（majority voting）指的是哪个步骤？

<div class="upper-alpha" markdown>
1. 选择在验证精度上表现最高的 K 值
2. 分配在 K 个最近邻中出现最频繁的类别标签
3. 按每个邻居到查询点的距离的倒数加权每个邻居的投票
4. 通过随机选择一个并列类别来消除平局
</div>

??? question "显示答案"
    正确答案是 **B**。在标准 KNN 中，预测类别是 K 个最近邻中出现最多（多数票）的类别。如果 K=5，有3个邻居是 A 类，2个是 B 类，则预测为 A 类。这种简单的投票规则对所有邻居一视同仁，无论它们与查询点的距离有多近。

    **考察概念：** Majority Voting

---

#### 6. 什么是加权 KNN（weighted KNN），它相较于标准 KNN 有什么优势？

<div class="upper-alpha" markdown>
1. 带归一化特征的 KNN；当特征具有不同测量尺度时提高精度
2. 每个邻居的投票按相似度函数（如距离的倒数）加权的 KNN，给予更近邻居更多影响力
3. 在距离计算中应用 L2 正则化以防止 overfitting 的 KNN
4. K 在训练期间通过交叉验证自动确定的 KNN
</div>

??? question "显示答案"
    正确答案是 **B**。加权 KNN 为每个邻居分配与其近邻程度成比例的投票权重（如权重 = 1/距离）。更近的邻居对预测的影响比远处的邻居更大。这比等权重更合理，因为不同类的非常近的邻居应该比许多相同类的远处邻居更受信任。

    **考察概念：** Weighted KNN、Similarity Function

---

#### 7. 在 KNN 中选择非常小的 K 值（如 K=1）会产生什么效果？

<div class="upper-alpha" markdown>
1. 模型欠拟合（underfitting）——它泛化太广，忽略了局部结构
2. 模型过拟合（overfitting）——它对单个训练样本和噪声过于敏感
3. 模型对大多数数据集实现最优的偏差-方差平衡
4. 模型产生比更大 K 值更平滑的决策边界
</div>

??? question "显示答案"
    正确答案是 **B**。K=1 时，查询点由其单个最近邻分类。这会产生非常不规则、锯齿状的决策边界，跟随每个训练点，包括噪声异常值。小 K → 高方差（overfitting）。大 K → 高偏差（更平滑但可能不准确的边界）。K 值选择管理这种权衡。

    **考察概念：** K Value Selection

---

#### 8. 为什么在应用 KNN 之前对特征进行归一化（normalize features）很重要？

<div class="upper-alpha" markdown>
1. KNN 要求所有特征在距离计算前具有相同数量的唯一值
2. 不同尺度的特征对距离产生不均等的贡献，导致幅度较大的特征主导距离计算
3. 归一化减少了训练集大小，使 KNN 的预测时间计算更快
4. 对于具有连续值的未归一化特征，KNN 的多数投票是未定义的
</div>

??? question "显示答案"
    正确答案是 **B**。KNN 直接在特征空间中使用距离。以千为单位测量的特征（如收入）会主导以小单位测量的特征（如年龄，以年为单位），使较大尺度的特征决定最近邻，无论其相关性如何。归一化（如标准化）在计算距离前将所有特征置于可比较的尺度上。

    **考察概念：** K-Nearest Neighbor、Distance Metric

---

#### 9. 什么是超参数调整（hyperparameter tuning），为什么 KNN 中的 K 被称为超参数（hyperparameter）而非参数？

<div class="upper-alpha" markdown>
1. K 是超参数，因为它在训练期间通过梯度下降（gradient descent）学习，不像模型权重
2. K 是超参数，因为它在训练前设置，控制学习算法本身而非从数据中学习
3. K 是超参数，因为它决定距离计算中使用的特征数量
4. K 是超参数，因为它在训练期间随模型适应数据而自动变化
</div>

??? question "显示答案"
    正确答案是 **B**。超参数是在训练前做出的配置选择，控制学习过程本身。KNN 中的 K 由工程师选择（不从数据中学习），决定查询多少个邻居。超参数调整是寻找最佳 K 值的过程（如通过交叉验证），以获得最佳泛化性能。

    **考察概念：** Hyperparameter Tuning、K Value Selection

---

#### 10. 与参数模型相比，KNN 在预测时的主要计算劣势是什么？

<div class="upper-alpha" markdown>
1. KNN 每次添加新样本时需要在完整数据集上重新训练
2. KNN 对每个预测必须计算到所有训练样本的距离，对于大型训练集速度很慢
3. KNN 无法在多个处理器上并行化，不像梯度下降
4. KNN 在预测时需要梯度计算，这比简单的前向传播（forward pass）更慢
</div>

??? question "显示答案"
    正确答案是 **B**。对于每个预测，KNN 必须计算查询点到 n 个训练样本中每一个的距离——这是一个 O(n × d) 的操作，其中 d 是维度。对于大型数据集（数百万个样本），这非常慢。参数模型（逻辑回归、神经网络）存储学习的参数，无论训练集大小如何，都能在 O(d) 时间内进行预测。

    **考察概念：** K-Nearest Neighbor、Nonparametric Method
