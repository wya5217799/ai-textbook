# 参考文献：线性回归

1. [Linear regression](https://en.wikipedia.org/wiki/Linear_regression) - Wikipedia — 全面介绍 linear regression 的数学建模、假设条件、ordinary least squares 和 evaluation metric。

2. [Mean squared error](https://en.wikipedia.org/wiki/Mean_squared_error) - Wikipedia — 详细解释 MSE 作为 loss metric 的数学定义、性质、与 RMSE 的关系，以及在 regression evaluation 中的应用。

3. [Ordinary least squares](https://en.wikipedia.org/wiki/Ordinary_least_squares) - Wikipedia — 介绍 normal equation 和 linear regression 的解析解，包括通过 residual 和 sums of squares 进行的几何解释。

4. The Elements of Statistical Learning (2nd Edition) - Trevor Hastie, Robert Tibshirani, Jerome Friedman - Springer — 第 3 章对 linear regression 的线性方法进行严格数学阐述，包括 normal equation、几何解释和模型评估。

5. Pattern Recognition and Machine Learning - Christopher Bishop - Springer — 第 3 章从概率视角讲解 linear regression，将 MSE 与 maximum likelihood 相联系，并引入正则化变体。

6. [Linear Regression in Machine Learning](https://www.geeksforgeeks.org/ml-linear-regression/) - GeeksforGeeks — 实践教程，涵盖 linear regression 的模型建立、cost function、normal equation，以及用 scikit-learn 的 Python 实现。

7. [Scikit-learn Linear Models](https://scikit-learn.org/stable/modules/linear_model.html) - Scikit-learn Official Docs — scikit-learn 中 linear regression 及相关模型的官方文档，附代码示例、数学背景和参数说明。

8. [R-squared (Coefficient of Determination)](https://www.geeksforgeeks.org/r-squared/) - GeeksforGeeks — 解释 R² 作为 regression model 拟合优度指标的含义，附公式、解读指南，以及与 MSE/RMSE 的对比。

9. [Linear Regression using PyTorch](https://www.geeksforgeeks.org/linear-regression-using-pytorch/) - GeeksforGeeks — 使用 PyTorch 从零实现 linear regression 的教程，展示 tensor operation 和 autograd 如何应用于这一基础算法。

10. [Gradient Descent Algorithm and Its Variants](https://www.geeksforgeeks.org/gradient-descent-algorithm-and-its-variants/) - GeeksforGeeks — 讲解 gradient descent 作为 normal equation 迭代替代方案的原理，与本章解析方法形成互补。
