# 参考文献：数据采集与探索

1. [Training, validation, and test data sets](https://en.wikipedia.org/wiki/Training,_validation,_and_test_data_sets) - Wikipedia — 解释 dataset split 的方式，阐述 training、validation、test set 各自的角色，以及 MNIST 等 benchmark dataset 在 ML 模型评估中的重要性。

2. [MNIST database](https://en.wikipedia.org/wiki/MNIST_database) - Wikipedia — 详细介绍 MNIST 手写数字数据集的来源、结构及其作为图像分类标准 benchmark 的地位。

3. [Data augmentation](https://en.wikipedia.org/wiki/Data_augmentation) - Wikipedia — 全面覆盖图像和文本数据的 data augmentation 技术，解释合成数据生成如何扩充 training set。

4. Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (3rd Edition) - Aurélien Géron - O'Reilly Media — 第 2–3 章通过真实数据集的 Python 实操，完整呈现 data acquisition 和 exploration 的工作流程。

5. Data Science for Business - Foster Provost, Tom Fawcett - O'Reilly Media — 从商业与工程视角解释 dataset selection、annotation strategy 和 data exploration，契合本课程学生的背景。

6. [Data Collection for Machine Learning](https://www.geeksforgeeks.org/ml-understanding-data-processing/) - GeeksforGeeks — 讲解 machine learning 数据理解与处理的实践指南，涵盖数据类型、数据来源和探索技术。

7. [Exploratory Data Analysis](https://www.geeksforgeeks.org/what-is-exploratory-data-analysis/) - GeeksforGeeks — 介绍 EDA 技术，包括汇总统计、分布分析和可视化方法，帮助在建模前理解数据集。

8. [ImageNet](https://en.wikipedia.org/wiki/ImageNet) - Wikipedia — 概述 ImageNet 大规模视觉识别数据集，包括其构建过程、标注流程，以及对 deep learning 研究的变革性影响。

9. [Data Annotation Guide](https://www.ibm.com/think/topics/data-annotation) - IBM Think — 权威介绍 supervised learning 数据集的 data annotation 方法、标注策略和标注质量控制。

10. [Kaggle Datasets](https://www.kaggle.com/datasets) - Kaggle — 跨领域的海量公开数据集仓库，为 machine learning 实验和课程作业提供丰富的实践数据源。
