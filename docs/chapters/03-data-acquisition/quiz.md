# 测验：数据获取与探索

通过以下题目测试你对 machine learning 数据收集、标注和探索的理解。

---

#### 1. 用于 supervised learning 的带标签数据集的结构是什么？

<div class="upper-alpha" markdown>
1. 按复杂度组织的算法集合
2. 每个数据点的输入特征与正确输出标签配对的集合
3. 来自先前训练网络的模型权重数据库
4. 专家系统使用的预定义规则库
</div>

??? question "显示答案"
    正确答案是 **B**。在 supervised learning 中，数据集中的每个数据点由输入特征和关联的标签（正确答案）组成。算法利用这些带标签的样本学习从输入到输出的映射。Unsupervised 数据集只包含输入，没有标签。

    **考察概念：** Dataset、数据获取

---

#### 2. 表格数据（tabular data）的基本组织方式是什么？

<div class="upper-alpha" markdown>
1. 具有高度、宽度和颜色通道的像素值三维数组
2. 行表示样本、列表示特征
3. 以 JSON 格式存储的按时间顺序排列的测量序列
4. 节点表示样本、边表示相似性的图结构
</div>

??? question "显示答案"
    正确答案是 **B**。表格数据的组织方式类似电子表格：每行代表一个样本（数据点），每列代表一个特征（属性）。Pandas DataFrame 等工具能自然地处理表格数据。图像数据（A）使用多维数组，图数据（D）则使用完全不同的结构。

    **考察概念：** 表格数据（Tabular Data）

---

#### 3. 图像数据在表示方式上与表格数据有何根本不同？

<div class="upper-alpha" markdown>
1. 图像数据只能以 CSV 格式存储，而表格数据使用数据库
2. 图像数据以具有固有空间结构的二维或三维像素值数组表示
3. 图像数据需要分类标签；表格数据需要数值标签
4. 图像数据的特征比表格数据少，因此处理更简单
</div>

??? question "显示答案"
    正确答案是 **B**。灰度图像是像素亮度值的二维数组（高度 × 宽度）。彩色图像增加了一个通道维度，RGB 图像的形状为（高度，宽度，3）。空间结构意味着相邻像素是相关的，convolutional neural networks 通过局部连接来利用这一特性。表格数据不具备这种空间组织方式。

    **考察概念：** 图像数据（Image Data）

---

#### 4. MNIST 数据集是什么？为什么它在 machine learning 研究中被广泛使用？

<div class="upper-alpha" markdown>
1. 用于自然语言处理基准测试的英文文档集合
2. 用于欺诈检测训练的大型金融交易数据库
3. 包含70,000张手写数字图像、用作分类算法基准的数据集
4. 通过模拟生成的用于测试回归模型的合成数据集
</div>

??? question "显示答案"
    正确答案是 **C**。MNIST 包含70,000张手写数字（0-9）的灰度图像，分为60,000张训练样本和10,000张测试样本。每张图像为28×28像素。它被广泛用作基准数据集，因为其规模足够小，训练速度快，且经过充分研究，为分类算法提供了标准的比较基准。

    **考察概念：** MNIST Dataset、Benchmark Dataset

---

#### 5. 什么是数据标注（data annotation），为什么它对 supervised learning 是必要的？

<div class="upper-alpha" markdown>
1. 在训练前压缩数据集以减少存储需求
2. 为原始数据点分配有意义的标签，创建 supervised learning 所需的带标签样本
3. 将数据集分为训练集、验证集和测试集
4. 从数据库中删除重复记录以提高数据质量
</div>

??? question "显示答案"
    正确答案是 **B**。数据标注（labeling）通过为每个输入分配真实值（ground-truth）输出，将原始未标注数据转化为带标签的数据集。没有标签，supervised learning 算法就无法计算误差和更新参数。标注方式包括分类标签、目标检测的边界框以及像素级分割掩码。

    **考察概念：** Data Annotation

---

#### 6. ImageNet 数据集是什么？它对 deep learning 有何重要意义？

<div class="upper-alpha" markdown>
1. 用于语音识别系统基准测试的1,000段音频录音集合
2. 包含超过1,400万张带标签图像的大规模数据集，推动了 computer vision 的 deep learning 突破
3. 由计算机图形软件生成的合成图像数据集，用于 CNN 测试
4. 专门用于医疗 AI 应用的医学扫描图像数据集
</div>

??? question "显示答案"
    正确答案是 **B**。ImageNet 包含超过1,400万张手工标注的图像，跨越20,000多个类别。使用1,000类子集的年度 ILSVRC 竞赛推动了 computer vision 的重大进步。AlexNet 在2012年的胜利展示了深度 CNN 的强大力量，并开启了现代 deep learning 时代。

    **考察概念：** ImageNet Dataset、Benchmark Dataset

---

#### 7. 为什么在 machine learning 训练过程中使用数据增强（data augmentation）？

<div class="upper-alpha" markdown>
1. 减少训练数据规模以加快模型训练速度
2. 通过对数据应用变换来人为扩展训练集，减少过拟合（overfitting）并提高泛化能力
3. 用统计估计值替换数据集中的缺失值
4. 将分类标签转换为数值代码以便处理
</div>

??? question "显示答案"
    正确答案是 **B**。Data augmentation 通过对现有数据应用变换（如旋转、翻转或裁剪图像）来创建新的训练样本。这在无需额外数据收集的情况下人为增加了数据集的规模和多样性，有助于模型更好地泛化并减少 overfitting。当带标签数据稀缺时尤其有价值。

    **考察概念：** Data Augmentation

---

#### 8. 什么是合成数据（synthetic data）？工程师在什么情况下会选择使用它？

<div class="upper-alpha" markdown>
1. 无需人工参与、由传感器自动收集的数据，在标注成本高昂时使用
2. 人工生成的模拟真实数据属性的数据，在真实数据稀缺、成本高昂或涉及隐私时使用
3. 从公开研究存储库借用以扩充小型私有数据集的数据
4. 经领域专家清洗和验证的噪声数据，用于高质量训练
</div>

??? question "显示答案"
    正确答案是 **B**。Synthetic data 是通过程序生成的——通过模拟、生成模型或数学过程——而非从现实世界收集。当真实数据稀缺（罕见事件）、收集成本高昂或隐私法规阻止使用真实用户数据时，它非常有用。风险在于合成数据可能无法完全代表真实世界的分布。

    **考察概念：** Synthetic Data

#### 9. 模型训练前进行探索性数据分析（EDA，Exploratory Data Analysis）的目的是什么？

<div class="upper-alpha" markdown>
1. 在不使用带标签数据的情况下调整模型的超参数（hyperparameters）
2. 检查数据集属性，包括分布、关系和异常，以指导预处理决策
3. 使用分层抽样将数据分为训练集和测试集
4. 在训练后对测试数据进行模型性能评估
</div>

??? question "显示答案"
    正确答案是 **B**。探索性数据分析（EDA）是在训练前检查数据集以了解其结构的实践：检查缺失值、可视化特征分布、识别相关性以及检测异常值或异常情况。EDA 的发现直接指导预处理决策和算法选择，防止训练过程中出现意外。

    **考察概念：** 数据探索（Data Exploration）

---

#### 10. 什么是数据整合（data integration）？为什么它在 machine learning 项目中存在挑战？

<div class="upper-alpha" markdown>
1. 将数据从文本格式转换为数值数组作为模型输入
2. 将来自多个来源的数据合并为统一数据集，需要协调不同的格式、模式和质量水平
3. 将大型数据集跨多台机器分区以进行分布式训练
4. 使用集成方法（ensemble methods）合并多个分类器的模型预测
</div>

??? question "显示答案"
    正确答案是 **B**。Data integration 涉及将来自异构来源（数据库、传感器、API、文件）的数据合并为统一数据集。挑战包括不同的 schema（列名、数据类型）、同一实体的冲突值、不同的采样频率以及不同的数据质量。整合不当会引入影响模型性能的不一致性。

    **考察概念：** Data Integration
