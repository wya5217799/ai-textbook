# 参考文献：分类与逻辑回归

1. [Logistic regression](https://en.wikipedia.org/wiki/Logistic_regression) - Wikipedia — 全面介绍 logistic function、binary 和 multinomial logistic regression、decision boundary 以及用于分类的 maximum likelihood estimation。

2. [Sigmoid function](https://en.wikipedia.org/wiki/Sigmoid_function) - Wikipedia — 介绍 sigmoid function 的数学定义和性质，包括其 S 形曲线、输出范围（0–1）及在分类模型中作为概率估计器的用途。

3. [Softmax function](https://en.wikipedia.org/wiki/Softmax_function) - Wikipedia — 详细解释用于 multi-class classification 的 softmax function，包括其与 sigmoid 的关系及在 neural network 输出层中的应用。

4. Pattern Recognition and Machine Learning - Christopher Bishop - Springer — 第 4 章从概率解释角度介绍 linear discriminant model 和 logistic regression，将 classification 与 maximum likelihood 训练目标相联系。

5. Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (3rd Edition) - Aurélien Géron - O'Reilly Media — 第 4 章以实践为主，通过 Python 代码讲解 logistic regression，涵盖 binary 和 multi-class classification。

6. [Logistic Regression using Python (Scikit-learn)](https://www.geeksforgeeks.org/ml-logistic-regression-using-python/) - GeeksforGeeks — 使用 scikit-learn 在真实数据集上实现 logistic regression 的步骤教程，包括 accuracy、confusion matrix 和 ROC 评估。

7. [Cross-Entropy Loss Function](https://www.geeksforgeeks.org/cross-entropy-loss-function/) - GeeksforGeeks — 解释 cross-entropy 作为分类训练目标的原理，附数学推导及与 maximum likelihood estimation 的关系。

8. [One-Hot Encoding](https://www.geeksforgeeks.org/ml-one-hot-encoding/) - GeeksforGeeks — 介绍 one-hot encoding 处理类别标签的方法，解释为何 multi-class logistic regression 和 neural network 输出层需要这种编码方式。

9. [Decision Boundary in Machine Learning](https://www.geeksforgeeks.org/decision-boundary-in-machine-learning/) - GeeksforGeeks — 可视化解释线性和非线性 decision boundary，展示 logistic regression 如何在 feature space 中分离不同类别。

10. [Scikit-learn Logistic Regression](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html) - Scikit-learn Official Docs — LogisticRegression 的官方 API 文档，涵盖 multi-class strategy、regularization 参数、solver 选项和使用示例。
