# 参考文献：循环神经网络与 ML 工作流

1. [Recurrent neural network](https://en.wikipedia.org/wiki/Recurrent_neural_network) - Wikipedia — 全面介绍 RNN 架构，包括 hidden state recurrence relation、backpropagation through time（BPTT），以及序列建模中的 vanishing gradient problem。

2. [Long short-term memory](https://en.wikipedia.org/wiki/Long_short-term_memory) - Wikipedia — 详细解释 LSTM 架构，包括 forget gate、input gate、cell state 和 output gate，以及它们如何解决 RNN 中的 vanishing gradient problem。

3. [Machine learning pipeline](https://en.wikipedia.org/wiki/Pipeline_(machine_learning)) - Wikipedia — 概述端到端 machine learning pipeline，从数据采集经 preprocessing、model training、evaluation 到生产系统 deployment 的完整流程。

4. Deep Learning (Adaptive Computation and Machine Learning Series) - Ian Goodfellow, Yoshua Bengio, Aaron Courville - MIT Press — 第 10 章以严格数学方式介绍 recurrent network 和 LSTM 架构；第 11 章讲解完整 ML workflow 的实践方法论。

5. Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (3rd Edition) - Aurélien Géron - O'Reilly Media — 第 15–16 章提供 RNN 和 LSTM 在序列数据上的 Python 实现，并涵盖完整的 ML deployment pipeline。

6. [Recurrent Neural Networks Explanation](https://www.geeksforgeeks.org/recurrent-neural-networks-explanation/) - GeeksforGeeks — 教程涵盖 RNN 架构、hidden state 计算、BPTT 训练和 vanishing gradient 挑战，附序列任务的实际应用。

7. [Long Short-Term Memory (LSTM) Networks](https://www.geeksforgeeks.org/long-short-term-memory-networks-explanation/) - GeeksforGeeks — 解释 LSTM gate 机制（forget、input、output），以及它们如何在序列数据中实现长程依赖的学习。

8. [PyTorch RNN Tutorial](https://docs.pytorch.org/tutorials/intermediate/char_rnn_classification_tutorial.html) - PyTorch Official Docs — 官方教程，使用 RNN 实现字符级文本分类，演示序列处理、hidden state 管理和 PyTorch 训练。

9. [Machine Learning Workflow](https://www.geeksforgeeks.org/machine-learning-workflow/) - GeeksforGeeks — 完整 ML pipeline 的端到端概述，从问题定义和数据收集，到 model training、evaluation 和 deployment 各步骤。

10. [LSTM vs RNN](https://www.geeksforgeeks.org/difference-between-rnn-and-lstm-in-deep-learning/) - GeeksforGeeks — 并列比较标准 RNN 和 LSTM 架构，解释各自的适用场景，以及 LSTM gate 如何解决 vanilla RNN 的局限性。
