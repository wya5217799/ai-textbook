# 参考文献：优化与梯度下降

1. [Gradient descent](https://en.wikipedia.org/wiki/Gradient_descent) - Wikipedia — 全面综述 gradient descent，包括数学建模、收敛条件以及 batch、stochastic、mini-batch 三种主要变体。

2. [Stochastic gradient descent](https://en.wikipedia.org/wiki/Stochastic_gradient_descent) - Wikipedia — 详细介绍 SGD 及其变体，包括 momentum、Adam 和 RMSProp，涵盖 learning rate 参数及其对收敛行为的影响。

3. [Mathematical optimization](https://en.wikipedia.org/wiki/Mathematical_optimization) - Wikipedia — 优化理论基础综述，涵盖 objective function、局部极小值与全局极小值，以及 convex 与 non-convex 优化的格局。

4. Deep Learning (Adaptive Computation and Machine Learning Series) - Ian Goodfellow, Yoshua Bengio, Aaron Courville - MIT Press — 第 8 章权威讲解 deep learning 优化，包括 SGD 变体、learning rate schedule 和收敛理论。

5. Optimization for Machine Learning - Suvrit Sra, Sebastian Nowozin, Stephen Wright (Eds.) - MIT Press — 高级参考书，深入介绍用于训练 ML 模型的梯度优化方法的理论基础。

6. [Gradient Descent Algorithm and Its Variants](https://www.geeksforgeeks.org/gradient-descent-algorithm-and-its-variants/) - GeeksforGeeks — 易读的 batch GD、SGD 和 mini-batch GD 教程，附跨 linear regression、logistic regression 和 neural network 的 Python 实现。

7. [Learning Rate in Machine Learning](https://www.geeksforgeeks.org/impact-of-learning-rate-on-model-performance/) - GeeksforGeeks — Learning rate 选择策略实践指南，涵盖固定 rate、learning rate schedule，以及过高或过低 rate 对收敛的影响。

8. [PyTorch Optimization Tutorial](https://docs.pytorch.org/tutorials/beginner/basics/optimization_tutorial.html) - PyTorch Official Docs — 官方教程，展示如何在完整 training loop 中使用 PyTorch optimizer（SGD、Adam）实现 gradient descent。

9. [Visualizing the Loss Landscape of Neural Networks](https://www.geeksforgeeks.org/loss-functions-in-deep-learning/) - GeeksforGeeks — 在 deep learning 模型训练背景下解释 loss landscape、saddle point 和 local minima。

10. [Mini-batch Gradient Descent](https://www.geeksforgeeks.org/ml-mini-batch-gradient-descent-with-python/) - GeeksforGeeks — 专门介绍 mini-batch gradient descent 的 Python 实现教程，解释 batch 方法与 stochastic 方法之间的权衡。
