# 参考文献：机器学习数学基础

1. [Matrix (mathematics)](https://en.wikipedia.org/wiki/Matrix_(mathematics)) - Wikipedia — 矩阵运算的全面参考，包括 matrix multiplication、transposition、inversion 及其几何解释，是理解 ML 算法的必备基础。

2. [Probability distribution](https://en.wikipedia.org/wiki/Probability_distribution) - Wikipedia — 综述 probability distribution，包括 Gaussian 和 Bernoulli distribution 的参数及其在统计 ML 模型中的作用。

3. [Maximum likelihood estimation](https://en.wikipedia.org/wiki/Maximum_likelihood_estimation) - Wikipedia — 详细讲解 MLE 作为训练 ML 模型的统计基础，包括 log-likelihood 的推导及其与 loss function 的关系。

4. Mathematics for Machine Learning - Marc Peter Deisenroth, A. Aldo Faisal, Cheng Soon Ong - Cambridge University Press — 专为 ML 背景设计的数学教材，覆盖 linear algebra、calculus、probability 和 optimization，可免费在线获取。

5. The Elements of Statistical Learning (2nd Edition) - Trevor Hastie, Robert Tibshirani, Jerome Friedman - Springer — 第 1–3 章对 loss function、model complexity 和统计估计进行严格的数学阐述，贯穿本课程始终。

6. [Linear Algebra for Machine Learning](https://www.geeksforgeeks.org/linear-algebra-machine-learning/) - GeeksforGeeks — 讲解 linear algebra 概念的实践指南，包括 vector、matrix、eigenvalue 及其在 ML 算法中的直接应用。

7. [Loss Functions in Machine Learning](https://www.geeksforgeeks.org/ml-common-loss-functions/) - GeeksforGeeks — 解释常见 loss function，包括 mean squared error、cross-entropy，以及它们作为模型训练 objective function 的作用。

8. [Probability Distributions in Machine Learning](https://www.geeksforgeeks.org/probability-distributions-used-in-machine-learning/) - GeeksforGeeks — 介绍 Gaussian、Bernoulli 等用于建模数据和定义概率 ML 模型的 distribution。

9. [3Blue1Brown: Essence of Linear Algebra](https://www.youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab) - YouTube (3Blue1Brown) — 关于 linear algebra 的可视化视频系列，涵盖 vector、matrix 和 transformation，强烈推荐用于建立几何直觉。

10. [Khan Academy: Probability and Statistics](https://www.khanacademy.org/math/statistics-probability) - Khan Academy — 免费自学课程，覆盖 probability、distribution 和统计估计，为理解 machine learning 理论提供统计学背景。
