# 参考文献：卷积神经网络

1. [Convolutional neural network](https://en.wikipedia.org/wiki/Convolutional_neural_network) - Wikipedia — 全面介绍 CNN 架构，包括 convolution operation、pooling layer、fully connected layer，以及从 LeNet-5 到 ResNet 的主要架构演变。

2. [Convolution](https://en.wikipedia.org/wiki/Convolution) - Wikipedia — 介绍 convolution operation 的数学定义与性质，为理解 CNN filter 如何从图像中提取空间特征提供理论基础。

3. [LeNet](https://en.wikipedia.org/wiki/LeNet) - Wikipedia — 概述 LeNet-5 架构的历史意义——作为第一个成功用于数字识别的 CNN——以及其对现代卷积网络设计的影响。

4. Deep Learning (Adaptive Computation and Machine Learning Series) - Ian Goodfellow, Yoshua Bengio, Aaron Courville - MIT Press — 第 9 章权威阐述 convolutional network 的数学原理，包括 convolution、pooling，以及 local connectivity 和 weight sharing 的动机。

5. Deep Learning with PyTorch (1st Edition) - Eli Stevens, Luca Antiga, Thomas Viehmann - Manning Publications — 第 8–9 章在 PyTorch 中逐步构建 CNN 架构，涵盖 filter、feature map、pooling 和图像分类训练流程。

6. [Convolutional Neural Network in Machine Learning](https://www.geeksforgeeks.org/convolutional-neural-network-cnn-in-machine-learning/) - GeeksforGeeks — 易读教程，涵盖 CNN 组件（conv layer、pooling、fully connected layer）、训练方法和主要架构，附代码示例。

7. [PyTorch CNN Tutorial](https://docs.pytorch.org/tutorials/beginner/blitz/cifar10_tutorial.html) - PyTorch Official Docs — 官方教程，在 CIFAR-10 上训练 CNN，演示 filter 定义、feature map 可视化和端到端图像分类 PyTorch 实现。

8. [Image Classification using CNN](https://www.geeksforgeeks.org/image-classifier-using-cnn/) - GeeksforGeeks — 用 Python 构建图像分类器的实践指南，涵盖 dataset 加载、model 定义、training 和 evaluation。

9. [Object Detection](https://en.wikipedia.org/wiki/Object_detection) - Wikipedia — 综述基于 CNN 的目标检测方法，包括 R-CNN 和 YOLO 系列，为图像分类以外的 CNN 应用提供背景。

10. [Pooling Layers in CNNs](https://www.geeksforgeeks.org/cnn-introduction-to-pooling-layer/) - GeeksforGeeks — 解释 max pooling 和 average pooling，说明空间降维的重要性，以及 pooling 如何提升 CNN 的平移不变性。
