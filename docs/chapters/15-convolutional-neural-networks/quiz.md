# 测验：卷积神经网络

通过以下题目测试你对 CNN 架构、卷积运算、池化和 computer vision 应用的理解。

---

#### 1. 为什么全连接网络（fully connected networks）在处理高分辨率图像输入时遇到困难？

<div class="upper-alpha" markdown>
1. 全连接网络无法处理像素值；它们需要符号特征表示
2. 每个像素连接到每个神经元创建了大量参数，使网络不切实际且容易过拟合（overfitting）
3. 当输入维度超过784时，全连接网络无法通过反向传播（backpropagation）训练
4. 图像数据需要随时间的循环处理，全连接网络无法执行
</div>

??? question "显示答案"
    正确答案是 **B**。224×224的彩色图像有150,528个输入值。将这些输入连接到第一个隐藏层的仅256个神经元，一层就需要超过3800万个权重。这种参数爆炸在计算上是浪费的，并会导致严重的 overfitting。CNN 通过局部连接和权重共享来解决这一问题，大幅减少参数数量。

    **考察概念：** Convolutional Neural Network

---

#### 2. CNN 中的卷积运算（convolution operation）计算什么？

<div class="upper-alpha" markdown>
1. 矩形区域内的平均像素值，以降低空间分辨率
2. 输入与学习到的滤波器（filter）的逐元素乘积，在局部空间区域内求和，检测局部模式
3. 特征图（feature map）的矩阵逆，用于跨通道归一化激活
4. 所有空间位置对之间的点积，以捕获长距离依赖关系
</div>

??? question "显示答案"
    正确答案是 **B**。卷积运算将一个小滤波器（卷积核，kernel）滑过输入图像，计算滤波器与输入每个局部区域之间的逐元素乘积之和。这检测特定局部模式（边缘、纹理、形状）在每个位置的存在。相同的滤波器在每个位置应用，实现了平移不变（translation-invariant）的特征检测。

    **考察概念：** Convolution Operation

---

#### 3. CNN 中的特征图（feature map）是什么？

<div class="upper-alpha" markdown>
1. 将输入像素值映射到类别概率的查找表
2. 将单个滤波器滑过整个输入产生的输出，显示在每个位置检测到该滤波器模式的位置
3. 显示推理期间哪些神经元最活跃的可视化工具
4. 卷积层中所有学习权重值的集合
</div>

??? question "显示答案"
    正确答案是 **B**。特征图（激活图，activation map）是将单个滤波器应用于整个输入的输出。特征图中的每个值表示滤波器模式在输入中相应空间位置的存在和强度。卷积层中的多个滤波器产生多个特征图，每个检测不同的模式。

    **考察概念：** Feature Map

---

#### 4. 增加卷积滤波器的步长（stride）如何影响输出特征图？

<div class="upper-alpha" markdown>
1. 它通过跳过每隔一个滤波器位置来增加特征图大小
2. 它通过以更大的步长移动滤波器来减小特征图大小，采样更少的位置
3. 它通过增加卷积核大小使滤波器对更大尺度的模式敏感
4. 它在每个位置多次应用滤波器，提高模式检测精度
</div>

??? question "显示答案"
    正确答案是 **B**。步长（stride）控制滤波器每步移动多少个位置。步长=1时，滤波器一次移动一个像素，产生较大的特征图。步长=2时，跳过每隔一个位置，将特征图维度减半。较大的步长减少了空间分辨率和计算量，但可能遗漏细粒度的空间信息。

    **考察概念：** Stride

---

#### 5. 卷积层中填充（padding）的目的是什么？

<div class="upper-alpha" markdown>
1. 在数据集边缘周围添加额外的训练样本
2. 通过在应用滤波器前在输入边界添加零来保持空间维度
3. 减少层中滤波器的数量以限制参数数量
4. 仅对图像中心区域应用卷积运算，忽略边界
</div>

??? question "显示答案"
    正确答案是 **B**。没有填充，每次卷积都会减小特征图的空间维度（因为滤波器不能延伸到图像边界之外）。填充在输入周围添加零行和零列，允许"same"填充保持相同的空间维度，或"valid"填充允许维度减小。填充还确保边缘像素对卷积的贡献与中心像素相同。

    **考察概念：** Padding

---

#### 6. 最大池化（max pooling）在 CNN 架构中实现什么？

<div class="upper-alpha" markdown>
1. 它计算每个局部区域中特征值的加权平均值以平滑特征图
2. 它从每个局部池化窗口中选取最大值，减小空间维度并捕获最强的特征存在
3. 它归一化特征图值，使其在通道间具有零均值和单位方差
4. 它应用非线性激活函数以增加层的表达能力
</div>

??? question "显示答案"
    正确答案是 **B**。最大池化在特征图上滑动一个窗口（如2×2），并取每个窗口中的最大值。这减少了空间维度（下采样），降低了计算量并引入了平移不变性——特征的小移动会产生相同的池化输出。最大池化保留了最强的激活，保持了最显著的信息。

    **考察概念：** Max Pooling、Pooling Layer

---

#### 7. CNN 中展平层（flatten layer）的作用是什么？

<div class="upper-alpha" markdown>
1. 它对池化特征图应用最终的非线性激活函数，然后再进行分类
2. 它将卷积层的多维特征图转换为一维向量，作为全连接层的输入
3. 它通过对空间维度取平均来减少特征图中的通道数
4. 它归一化检测到的特征的空间坐标，使其与位置无关
</div>

??? question "显示答案"
    正确答案是 **B**。在卷积层和池化层产生三维特征图（高度 × 宽度 × 通道数）后，展平层将其重塑为一维向量。然后该向量被馈入一个或多个全连接层，将学习的空间特征组合起来产生最终的分类输出。展平层是空间特征提取和全局预测之间的桥梁。

    **考察概念：** Flatten Layer、CNN Architecture

#### 8. LeNet-5 在历史上具有重要意义，因为它展示了哪种能力？

<div class="upper-alpha" markdown>
1. 具有数百层的深度网络可以使用残差连接（residual connections）进行训练
2. 具有卷积层、池化和全连接层的 CNN 可以有效识别手写数字
3. Reinforcement learning 可以训练 CNN 无需人类监督即可玩视频游戏
4. 在大型数据集上预训练 CNN 能够以少量样本迁移学习（transfer learning）到新任务
</div>

??? question "显示答案"
    正确答案是 **B**。LeNet-5 由 Yann LeCun 及其同事于1998年设计，是最早成功的 CNN 之一，应用于 MNIST 数据集上的手写数字识别。其架构——两个带池化的卷积层，后跟全连接层——为现代 CNN 建立了模板，并证明了卷积架构可以解决现实世界的识别任务。

    **考察概念：** LeNet-5、CNN Architecture

#### 9. 在图像分割（image segmentation，与图像分类不同）中，模型预测什么？

<div class="upper-alpha" markdown>
1. 整个图像的单一类别标签
2. 图像中每个目标的边界框及其类别标签
3. 图像中每个单独像素的类别标签
4. 图像中每个像素距摄像机的深度或距离
</div>

??? question "显示答案"
    正确答案是 **C**。图像分割为图像中的每个像素分配一个类别标签，产生像素级的分类图。这比图像分类（整个图像的单一标签，A）更细粒度，比目标检测（目标周围的边界框，B）更详细。语义分割（semantic segmentation）按像素分配类别标签；实例分割（instance segmentation）区分各个目标。

    **考察概念：** Image Segmentation

#### 10. 卷积层中权重共享（weight sharing）的关键优势是实现了哪项好处？

<div class="upper-alpha" markdown>
1. 它允许相同的滤波器权重在每个空间位置应用，大幅减少可学习参数的数量
2. 它使不同层能够共享权重，减少网络所需的总深度
3. 它允许多个 GPU 在分布式训练期间共享相同的权重矩阵
4. 它防止任何单个神经元对输出产生不成比例的大影响
</div>

??? question "显示答案"
    正确答案是 **A**。在卷积层中，相同的滤波器（权重集合）在输入的每个空间位置应用。单个3×3滤波器无论输入大小如何只有9个权重，而全连接层中每个输出神经元需要每个输入像素一个权重。权重共享利用了自然图像的平移不变性：相同的模式检测器在任何位置都有用。

    **考察概念：** Convolutional Neural Network、Filter
