# 参考文献：回归模型评估

1. [Overfitting](https://en.wikipedia.org/wiki/Overfitting) - Wikipedia — 全面介绍 overfitting 和 underfitting，解释 model complexity、bias-variance tradeoff，以及 regularization 和 cross-validation 等应对策略。

2. [Regularization (mathematics)](https://en.wikipedia.org/wiki/Regularization_(mathematics)) - Wikipedia — 详细介绍 L1（Lasso）和 L2（Ridge）regularization，包括数学建模、几何解释及对模型系数的影响。

3. [Cross-validation (statistics)](https://en.wikipedia.org/wiki/Cross-validation_(statistics)) - Wikipedia — 全面讲解 k-fold、leave-one-out 等 cross-validation 策略，用于稳健的模型评估和 hyperparameter 选择。

4. The Elements of Statistical Learning (2nd Edition) - Trevor Hastie, Robert Tibshirani, Jerome Friedman - Springer — 第 7 章权威讲解模型评估与选择，涵盖 bias-variance tradeoff、cross-validation 和 regularization 方法。

5. Pattern Recognition and Machine Learning - Christopher Bishop - Springer — 第 3 章介绍正则化 linear regression 及模型复杂度的 Bayesian 视角，为 regularization 技术提供理论依据。

6. [Underfitting and Overfitting in Machine Learning](https://www.geeksforgeeks.org/underfitting-and-overfitting-in-machine-learning/) - GeeksforGeeks — 直观的可视化教程，解释 overfitting 和 underfitting 的诊断策略，以及 regularization 和 early stopping 等补救技术。

7. [Cross-Validation in Machine Learning](https://www.geeksforgeeks.org/cross-validation-machine-learning/) - GeeksforGeeks — 使用 scikit-learn 实现 K-fold cross-validation 的 Python 实践教程，演示如何获得更可靠的模型性能估计。

8. [L1 and L2 Regularization](https://www.geeksforgeeks.org/l1-and-l2-regularization/) - GeeksforGeeks — 并列比较 Lasso 和 Ridge regularization，附公式、Python 示例，以及各自适用场景的指导建议。

9. [Bias-Variance Tradeoff](https://www.geeksforgeeks.org/bias-vs-variance-in-machine-learning/) - GeeksforGeeks — 解释 bias-variance 分解与权衡曲线，将 underfitting（high bias）和 overfitting（high variance）与 model complexity 相联系。

10. [Scikit-learn Model Selection](https://scikit-learn.org/stable/modules/cross_validation.html) - Scikit-learn Official Docs — scikit-learn cross-validation utility 的官方文档，附 grid search、k-fold 和 stratified cross-validation 的代码示例。
