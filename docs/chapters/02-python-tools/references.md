# 参考文献：AI 编程工具：Python 生态

1. [NumPy](https://en.wikipedia.org/wiki/NumPy) - Wikipedia — 介绍 NumPy 作为 Python 数值计算基础库的概况，涵盖 array operation、broadcasting 及其在 scientific Python 生态中的地位。

2. [Pandas (software)](https://en.wikipedia.org/wiki/Pandas_(software)) - Wikipedia — 全面描述 Pandas 库、其 DataFrame 结构，以及在 machine learning pipeline 中用于数据操作和分析的方式。

3. [PyTorch](https://en.wikipedia.org/wiki/PyTorch) - Wikipedia — 综述 PyTorch 作为开源 deep learning 框架的特点，解释其 tensor computation engine 和 automatic differentiation 系统——这是贯穿本课程的核心工具。

4. Python for Data Analysis (3rd Edition) - Wes McKinney - O'Reilly Media — Pandas 创始人撰写的权威指南，直接覆盖课程实验所使用的 Pandas 和 NumPy 数据处理工具。

5. Deep Learning with PyTorch (1st Edition) - Eli Stevens, Luca Antiga, Thomas Viehmann - Manning Publications — PyTorch 实践入门，涵盖 tensor、neural network 和 training loop，是本课程 PyTorch 使用的主要参考书。

6. [Python Programming Language](https://www.geeksforgeeks.org/python-programming-language/) - GeeksforGeeks — 全面的 Python 教程，涵盖语法、数据结构、函数和 OOP，为所有课程实验提供必要的语言基础。

7. [PyTorch Fundamentals](https://docs.pytorch.org/tutorials/beginner/basics/intro.html) - PyTorch Official Docs — 逐步介绍完整的 PyTorch ML workflow，包括 tensor、dataset、model building、training 和模型保存。

8. [Jupyter Notebook](https://en.wikipedia.org/wiki/Project_Jupyter) - Wikipedia — 概述 Project Jupyter 和 Jupyter Notebook 作为所有课程实验和实验探索所用的交互式计算环境。

9. [Matplotlib](https://en.wikipedia.org/wiki/Matplotlib) - Wikipedia — 介绍 Matplotlib 作为标准 Python 可视化库的概况，涵盖其 pyplot 接口及在数据与模型输出可视化中的作用。

10. [Scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html) - Scikit-learn Official Docs — Scikit-learn 官方文档，涵盖所有 classical ML algorithm、preprocessing utility 和 evaluation tool——与 PyTorch 配合用于本课程。
