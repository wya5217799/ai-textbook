# 参考文献：聚类与无监督学习

1. [K-means clustering](https://en.wikipedia.org/wiki/K-means_clustering) - Wikipedia — 全面介绍 K-means 算法，包括算法步骤、收敛性质、centroid 初始化方法（k-means++），以及对非球形 cluster 的局限性。

2. [DBSCAN](https://en.wikipedia.org/wiki/DBSCAN) - Wikipedia — 详细解释 DBSCAN 算法机制，包括 core point、epsilon 邻域、density reachability、border point 和 noise point 识别。

3. [Principal component analysis](https://en.wikipedia.org/wiki/Principal_component_analysis) - Wikipedia — 数学与几何层面解释 PCA，包括 eigenvector、eigenvalue、方差最大化，以及其在高维数据集 dimensionality reduction 中的应用。

4. The Elements of Statistical Learning (2nd Edition) - Trevor Hastie, Robert Tibshirani, Jerome Friedman - Springer — 第 14 章以严格的统计方法介绍 unsupervised learning，包括 K-means clustering、hierarchical clustering 和 PCA。

5. Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow (3rd Edition) - Aurélien Géron - O'Reilly Media — 第 9 章提供 K-means、DBSCAN 和 PCA 的 scikit-learn Python 实现，包括 clustering 结果的可视化。

6. [K-Means Clustering in Machine Learning](https://www.geeksforgeeks.org/k-means-clustering-introduction/) - GeeksforGeeks — 易读教程，涵盖 K-means 迭代工作流、centroid 更新规则、用于选择 k 的 elbow method，以及 Matplotlib Python 实现。

7. [DBSCAN Clustering in Machine Learning](https://www.geeksforgeeks.org/dbscan-clustering-in-ml-density-based-clustering/) - GeeksforGeeks — DBSCAN 教程，涵盖 epsilon 和 min_samples 参数、core/border/noise point 分类，以及与 K-means 在非球形数据上的对比。

8. [Principal Component Analysis with Python](https://www.geeksforgeeks.org/principal-component-analysis-with-python/) - GeeksforGeeks — 使用 scikit-learn 的分步 PCA 实现，演示从 13 维特征降至 2 维主成分，并可视化 explained variance。

9. [Unsupervised Learning](https://www.geeksforgeeks.org/unsupervised-learning/) - GeeksforGeeks — 综述 unsupervised learning 范式，包括 clustering、dimensionality reduction 和 generative model，将这些算法定位于更广泛的 ML 领域中。

10. [Scikit-learn Clustering](https://scikit-learn.org/stable/modules/clustering.html) - Scikit-learn Official Docs — 官方文档，对比 scikit-learn 中所有 clustering 算法，附性能表格、参数指南和各方法的可视化 cluster 示例。
