## Description

This step-through MicroSim places tabular data and image data side-by-side across three stages:

- **Stage 1** — Raw representations: a 5-row spreadsheet vs an 8×8 grayscale pixel grid
- **Stage 2** — Feature extraction: feature columns vs. label, feature vector notation, flattened pixel array
- **Stage 3** — Algorithms: which ML libraries and models work best with each data type

Use **Previous / Next** to step through stages. Toggle **Show pixel values** to overlay the numerical pixel values on the image grid.

## Learning Objective

Compare the structure, representation, and typical use cases of tabular data versus image data in machine learning. (Bloom Level: Understand / compare)

## Lesson Plan

| Phase | Activity | Duration |
|-------|----------|----------|
| Explore | Step through all three stages; read both panels at each stage. | 4 min |
| Compare | What is the key structural difference between a feature vector from tabular vs image data? | 2 min |
| Apply | For a medical diagnosis task using patient records: tabular or image? What about chest X-rays? | 2 min |
