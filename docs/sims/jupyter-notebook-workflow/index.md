## Description

This flowchart walks through the nine standard steps of a machine learning project in Jupyter Notebook, arranged in two columns with connecting arrows:

1. Import Libraries → 2. Load Data → 3. Explore Data → 4. Visualise Data → 5. Preprocess Data
6. Define Model → 7. Train Model → 8. Evaluate Results → 9. Document Findings

Cell types are color-coded: **Blue** = Code, **Green** = Output, **Orange** = Plot, **Purple** = Markdown.

**Hover** any step card to see example Python code in the detail panel at the bottom. **Click** to pin the detail panel open.

## Learning Objective

Demonstrate the typical ML workflow using Jupyter Notebook by stepping through the sequence of cells from data loading to model evaluation. (Bloom Level: Apply / demonstrate)

## Lesson Plan

| Phase | Activity | Duration |
|-------|----------|----------|
| Read | Hover each step; identify which library is used at each stage. | 4 min |
| Discuss | Why must preprocessing (Step 5) always come before model training? | 2 min |
| Apply | Open a real Jupyter notebook and identify which step each cell belongs to. | 4 min |
