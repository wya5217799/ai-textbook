## Description

This step-through MicroSim presents each of the three machine learning paradigms in sequence:

1. **Supervised Learning** — labeled input-output pairs, learns a mapping function
2. **Unsupervised Learning** — unlabeled data, discovers hidden structure
3. **Reinforcement Learning** — agent + environment interaction, maximizes reward

Each stage includes a **Quick Check** quiz at the bottom. Click one of the three answer options to check your understanding before advancing.

Use the **Previous / Next** buttons to move between paradigms.

## Learning Objective

Compare the three primary machine learning paradigms by examining how each uses data, receives feedback, and formulates its goal. (Bloom Level: Understand / compare)

## Lesson Plan

| Phase | Activity | Duration |
|-------|----------|----------|
| Read | Step through all three paradigms; read the data, feedback, and goal boxes. | 4 min |
| Quiz | Answer the Quick Check question on each stage before moving on. | 3 min |
| Reflect | In your own words, state the key difference between supervised and reinforcement learning. | 3 min |
