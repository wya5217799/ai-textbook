# 课程简介

## 课程名称

H63AIS - Artificial Intelligence System（人工智能系统）

## 目标学生

宁波诺丁汉大学电气与电子工程学院三年级本科生。

## 先修要求

- 基础编程能力（Python）
- 基础数学（linear algebra、calculus、probability）

## 授课教师

Dr. Qianyu Liu，宁波诺丁汉大学电气与电子工程学院助理教授。研究方向：数据挖掘与智能决策；machine learning 技术与应用。

## 课程目标

深入考察人工智能系统的基本原理与策略，并探索其主要 model 与应用场景。

## 学习成果

完成本课程后，学生应能够：

- 描述各类 artificial intelligence 技术的学习策略背后的基本原理。
- 将 binary threshold logic neuron 应用于简单工程问题的求解。
- 设计 artificial intelligence 技术以解决工程问题。
- 批判性地评估各种 AI 技术在工程问题中的性能表现。

## 课程模块

### 数据与探索（Data and Exploration）

1. Data acquisition（数据采集）
2. Data annotation（数据标注）
3. Data exploration and analysis（数据探索与分析）
4. Data cleaning（数据清洗）
5. Feature engineering（特征工程）

### 机器学习基础（Fundamentals of Machine Learning）

1. Linear regression（线性回归）
2. K-nearest neighbor algorithm（K 近邻算法）
3. Logistic regression（逻辑回归）

### 监督学习（Supervised Learning）

1. Fully Connected Neural Network（全连接神经网络）
2. Convolutional Neural Network，CNN（卷积神经网络）
3. Recurrent Neural Network，RNN（循环神经网络）
4. Long Short-Term Memory，LSTM（长短期记忆网络）

### 无监督学习（Unsupervised Learning）

1. K-means clustering（K 均值聚类）
2. Principal component analysis，PCA（主成分分析）

### 强化学习（Reinforcement Learning）

1. Value based（基于价值）
2. Policy based（基于策略）

## 不涵盖的主题

- 深度 Natural Language Processing（NLP）
- Generative Adversarial Networks（GANs）实现
- Transformer 架构细节
- Large Language Model 训练
- 机器人学与自主系统
- CNN 基础以外的 computer vision 内容

## 软件与工具

- 编程语言：Python 3.X
- IDE：Jupyter Notebook / PyCharm
- 软件包：PyTorch、Scikit-learn、NumPy、Pandas、Matplotlib

## 课程背景

本课程对 artificial intelligence 和 machine learning 进行全面介绍，覆盖完整的 ML workflow——从 data acquisition、preprocessing 到 model training、evaluation 和 deployment。学生将通过 Python 和 PyTorch 获得 classical ML algorithm 与现代 deep learning 架构的实操经验。本课程面向有志于从事 data science、AI research 和 intelligent systems development 的工程专业学生。
