    测验：回归模型评估¶

    通过以下题目测试你对过拟合、正则化、交叉验证和偏差-方差权衡的理解。

    1. 在 machine learning 的语境中，泛化（generalization）是什么意思？¶

    1. 将在一种数据类型上训练的模型应用于完全不同的数据类型
    2. 训练模型在新的、之前未见过的数据上表现良好的能力
    3. 将模型从一个编程框架翻译到另一个框架的过程
    4. 通过减少模型参数数量来简化模型
    显示答案

    正确答案是 B。泛化（generalization）是模型在非训练数据上表现良好的能力。Machine learning 的全部目的是从训练数据中学习能转移到真实世界的模式。泛化不良——低训练误差但高测试误差——就是过拟合（overfitting）的定义。

    考察概念： Generalization

    2. 一个模型的训练误差为2%，验证误差为35%。这说明了什么？¶

    1. 欠拟合（Underfitting）——模型太简单，无法捕获任一数据集中的模式
    2. 良好泛化——两个误差都在可接受范围内
    3. 过拟合（Overfitting）——模型记住了训练数据，但无法泛化
    4. 数据泄露（Data leakage）——验证集意外包含在训练中
    显示答案

    正确答案是 C。训练误差非常低但验证误差非常高的大差距是 overfitting 的标志。模型学习了训练特有的噪声，而非可泛化的模式。欠拟合（A）在两个集合上都显示高误差。数据泄露（D）通常会导致验证误差异常低，而非高。

    考察概念： Overfitting、Training Error、Validation Error

    3. 哪种场景最好地描述了欠拟合（underfitting）？¶

    1. 模型参数过多，记住了包括噪声在内的训练数据
    2. 模型太简单，无法捕获潜在模式，导致训练集和验证集上的误差都很高
    3. 模型在训练数据上表现良好，但在保留的测试集上表现不佳
    4. 模型收敛到局部最小值而非全局最小值
    显示答案

    正确答案是 B。Underfitting 发生在模型缺乏捕获数据中真实关系的能力时。训练误差和验证误差都很高。解决方案包括增加模型复杂度、添加特征或训练更多 epoch。过拟合（A、C）显示训练误差和验证误差之间存在差距。

    考察概念： Underfitting

    4. L2 正则化（L2 regularization）在代价函数中添加了什么，其效果是什么？¶

    1. 参数绝对值之和，促使某些权重变为精确的零
    2. 参数平方值之和乘以惩罚系数，阻止大权重
    3. 训练集上预测的方差，稳定训练动态
    4. 非零参数的数量，惩罚模型稀疏性
    显示答案

    正确答案是 B。L2 正则化（Ridge）在代价函数中添加 λΣθⱼ²。这惩罚大参数值，将所有权重推向零，但很少完全为零。效果是产生更平滑、更不复杂的模型，减少 overfitting。λ 控制正则化强度：λ 越大 = 惩罚越强 = 模型越简单。

    考察概念： L2 Regularization、Regularization

    5. L1 正则化（L1 regularization）在对模型参数的效果上与 L2 正则化有何不同？¶

    1. L1 使用平方惩罚，产生平滑的小权重；L2 使用绝对值惩罚，产生稀疏权重，某些权重精确为零
    2. L1 使用绝对值惩罚，产生稀疏模型，某些权重精确为零；L2 使用平方惩罚，产生小但非零的权重
    3. L1 在模型评估期间应用；L2 在训练期间应用
    4. L1 仅对线性模型防止 overfitting；L2 仅对神经网络防止 overfitting
    显示答案

    正确答案是 B。L1 正则化（Lasso）在代价中添加 λΣ|θⱼ|。绝对值惩罚在零处具有不连续的导数，这会驱使某些权重精确地变为零，产生具有内置特征选择（feature selection）的稀疏模型。L2（Ridge）保持所有权重非零但很小。当许多特征不相关时，L1 的稀疏性属性使其非常有用。

    考察概念： L1 Regularization、L2 Regularization

    6. 提前停止（early stopping）作为正则化技术是什么？¶

    1. 当学习率达到最小阈值时停止训练
    2. 当验证损失开始增加时停止训练，防止模型过拟合训练数据
    3. 无论是否收敛，在固定 epoch 数后停止训练
    4. 当神经元的权重接近零时从网络中移除它们
    显示答案

    正确答案是 B。Early stopping 在训练期间监控验证损失，当验证损失停止减少（或开始增加）时停止过程，即使训练损失继续下降。这通过捕获模型泛化最佳的时刻来防止模型 overfitting。它是一种计算上免费的正则化形式，不需要额外的参数。

    考察概念： Early Stopping

    7. 在 k=5 的 k 折交叉验证（k-fold cross-validation）中，数据集如何用于模型评估？¶

    1. 数据集一次性分为80%训练和20%测试，在相同的划分上重复评估5次
    2. 数据集被分为5个相等的折（folds）；模型在4个折上训练，在1个折上评估，旋转5次，对结果取平均
    3. 在数据20%的随机子样本上训练5个不同的模型
    4. 在单次训练运行前将数据集扩充5次以提高泛化能力
    显示答案

    正确答案是 B。在5折交叉验证中，数据被分为5个相等的折。在5次迭代中的每一次，一个折作为验证集，另外四个作为训练数据。验证误差在5个折上取平均以产生鲁棒的性能估计。这使所有数据在各次迭代中都用于训练和验证。

    考察概念： Cross-validation

    8. 偏差-方差权衡（bias-variance tradeoff）指出模型误差可以分解为哪些组成部分？¶

    1. 训练误差和测试误差，两者之和始终为常数
    2. L1 误差和 L2 误差，代表不同的正则化贡献
    3. 偏差（Bias，来自错误假设的系统误差）、方差（Variance，对训练数据波动的敏感性）和不可约噪声
    4. 梯度误差和近似误差，源自不精确的数值优化
    显示答案

    正确答案是 C。偏差-方差分解将期望预测误差表示为：Bias² + Variance + 不可约噪声。Bias 是来自系统性模型假设的误差（高偏差 = 欠拟合）。Variance 是来自对训练数据敏感性的误差（高方差 = 过拟合）。不可约噪声是数据本身固有的。模型必须在偏差和方差之间权衡。

    考察概念： Bias-Variance Tradeoff

    9. 拟合到20个数据点的高度复杂模型（如15次多项式）可能表现出哪种偏差和方差的组合？¶

    1. 高偏差和低方差——模型对简单数据欠拟合
    2. 低偏差和低方差——模型对数据集大小完美校准
    3. 低偏差和高方差——模型紧密拟合训练点，但对包含哪些数据点高度敏感
    4. 高偏差和高方差——模型同时过度简化和过拟合
    显示答案

    正确答案是 C。15次多项式有足够的容量精确地经过所有20个点（低偏差——在训练数据上没有系统误差）。然而，不同的20个点集合会产生非常不同的多项式（高方差）。这种高方差模型过拟合：它捕获了当前训练集特有的噪声，而不是真正的底层函数。

    考察概念： Bias-Variance Tradeoff、Overfitting

    10. 对于显示高训练精度但低验证精度的模型，以下哪项行动最有可能减少 overfitting？¶

    1. 通过添加更多参数增加模型复杂度
    2. 移除验证集，使模型在所有可用数据上训练
    3. 应用 L2 正则化，收集更多训练数据，或使用 early stopping
    4. 增加学习率以更快逃离 overfitting 区域
    显示答案

    正确答案是 C。Overfitting 的解决措施包括正则化（L1 或 L2）以约束参数幅度，收集更多训练数据使模型无法记住每个样本，以及 early stopping 以在模型开始拟合噪声之前停止训练。增加模型复杂度（A）会加剧 overfitting，移除验证集（B）会消除检测 overfitting 的能力。

    考察概念： Overfitting、Regularization、Generalization
