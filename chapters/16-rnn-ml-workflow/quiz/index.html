    测验：循环神经网络与 ML 工作流¶

    通过以下题目测试你对 RNN、LSTM 和端到端 machine learning 流程的理解。

    1. 序列数据的哪个属性使其不适合标准全连接网络处理？¶

    1. 序列数据包含太多特征，全连接网络无法高效处理
    2. 序列数据中的元素具有有意义的顺序和时序依赖关系，固定大小的架构无法捕获
    3. 序列数据总是分类的，需要在全连接网络处理前进行特殊编码
    4. 序列数据的类别太多，softmax 无法产生良好校准的概率分布
    显示答案

    正确答案是 B。序列数据（时间序列、文本、音频）具有时序结构：时间步 t 的值可能依赖于早期值，改变顺序会改变含义。标准全连接网络独立处理每个时间步，且具有固定大小的输入，因此无法捕获可变长度的序列或时序依赖关系。

    考察概念： Sequence Data

    2. 循环神经网络（RNN，Recurrent Neural Network）中的隐藏状态（hidden state）是什么？¶

    1. 在反向传播（backpropagation through time）期间不更新的权重集合
    2. 跨时间步维护的向量，编码序列中所有先前输入的信息
    3. 网络处理整个序列后最后一层产生的输出
    4. 不直接连接到输入或输出的中间层神经元
    显示答案

    正确答案是 B。隐藏状态 hₜ 是 RNN 的"记忆"——在每个时间步根据当前输入 xₜ 和先前隐藏状态 hₜ₋₁ 更新的向量：hₜ = f(Wxₜ + Uhₜ₋₁ + b)。它携带来自所有先前时间步的信息向前传递，使网络能够捕获时序依赖关系。相同的权重矩阵 W 和 U 在所有时间步共享。

    考察概念： Hidden State、Recurrent Neural Network

    3. 标准 RNN 在处理很长序列时会遇到什么问题？¶

    1. 它们无法处理长于隐藏层神经元数量的输入
    2. 当梯度通过许多时间步反向传播时，梯度会消失或爆炸，使学习长距离依赖关系变得困难
    3. 随着序列长度增加，它们需要指数级更多的内存，导致内存溢出
    4. 它们只能建模单调递增或递减的序列，而非任意时序模式
    显示答案

    正确答案是 B。在时间反向传播（BPTT，Backpropagation Through Time）期间，梯度在每个时间步都与相同的权重矩阵相乘。对于长序列，这些重复乘法导致梯度要么缩小到接近零（梯度消失，vanishing gradient），要么呈指数增长（梯度爆炸，exploding gradient）。梯度消失使学习遥远时间步之间的依赖关系变得不可能。

    考察概念： Recurrent Neural Network

    4. 长短期记忆（LSTM，Long Short-Term Memory）如何解决梯度消失问题？¶

    1. 通过使用 ReLU 激活代替 tanh，防止每个时间步的梯度饱和
    2. 通过使用由可学习门控制的单元状态（cell state），控制在每步添加、遗忘和输出什么信息
    3. 通过在处理 RNN 前对序列进行下采样来缩短序列长度
    4. 通过在每个时间步对隐藏状态应用批归一化（batch normalization）来归一化梯度幅度
    显示答案

    正确答案是 B。LSTM 引入了单元状态 Cₜ，可以以最小的修改跨许多时间步携带信息。三个门——遗忘门（forget gate，什么需要清除）、输入门（input gate，什么需要添加）和输出门（output gate，什么需要暴露）——使用 sigmoid 激活来选择性地管理单元状态。这种门控机制创建了抵制梯度消失的梯度路径，使长距离依赖关系的学习成为可能。

    考察概念： Long Short-Term Memory

    5. 以下哪个是 RNN 或 LSTM 非常适合处理的序列数据示例？¶

    1. 用于手写数字识别的单张28×28像素图像
    2. 用于价格预测的房屋特征（大小、年龄、位置）表格数据集
    3. 用于预测次日价格的365天每日股票价格时间序列
    4. 具有人口统计和购买历史特征的客户记录集合
    显示答案

    正确答案是 C。每日股票价格构成时间序列，每个值依赖于先前值——这正是 RNN 和 LSTM 被设计用来建模的序列结构。选项 A 和 B 是固定大小的输入，分别适合 CNN 和全连接网络。选项 D 虽然涉及历史记录，但通常是没有每条记录内部时序顺序的结构化表格数据。

    考察概念： Sequence Data、Recurrent Neural Network

    6. 在完整的 ML 工作流中，哪个阶段紧接在模型训练之前？¶

    1. 模型部署（Model deployment）——为训练好的模型准备基础设施
    2. 模型评估（Model evaluation）——在测试集上评估性能
    3. 数据预处理和特征工程（Data preprocessing and feature engineering）——清洗数据并将其转换为模型就绪的格式
    4. 超参数调整（Hyperparameter tuning）——选择最优模型配置
    显示答案

    正确答案是 C。ML 工作流遵循以下顺序：数据获取 → 数据预处理和特征工程 → 模型训练 → 模型评估 → 模型部署。预处理（清洗、归一化、划分）将原始数据转换为训练所需的格式。模型训练不能从原始的、未处理的数据开始。

    考察概念： ML Workflow

    7. 模型部署（model deployment）在端到端 ML 工作流中涉及什么？¶

    1. 将模型的源代码作为开源项目发布供其他研究者使用
    2. 使训练好的模型作为服务或嵌入式系统可用，以便对真实世界数据进行预测
    3. 将评估结果提交到基准排行榜与其他模型比较
    4. 在评估完成后，在完整数据集（包括测试数据）上重新训练模型
    显示答案

    正确答案是 B。模型部署将训练好的模型集成到生产环境中，以便在真实世界中提供预测服务。这可能涉及将模型封装在 API 中、嵌入固件中、打包进移动应用，或通过云平台提供服务。部署还涉及监控随时间推移的性能下降（数据漂移，data drift）。

    考察概念： Model Deployment、ML Workflow

    8. RNN 与标准全连接网络在架构上有什么区别？¶

    1. RNN 使用卷积滤波器处理输入，而不是线性权重矩阵
    2. RNN 具有循环连接，其中每个时间步的隐藏状态作为下一步的输入反馈
    3. RNN 同时并行处理整个序列；全连接网络一次处理一个样本
    4. RNN 只能使用 unsupervised learning 训练；全连接网络需要带标签数据
    显示答案

    正确答案是 B。RNN 的定义特征是循环连接：hₜ = f(xₜ, hₜ₋₁)。来自时间步 t-1 的隐藏状态作为时间步 t 的额外输入反馈回来。这个反馈循环允许网络在序列中维持状态。标准全连接网络没有这种循环连接，独立处理每个输入。

    考察概念： Recurrent Neural Network、Hidden State

    9. 为什么在 ML 工作流中持续监控部署后的模型很重要？¶

    1. 为了在没有人工干预的情况下自动地在新数据上继续训练模型
    2. 为了检测真实世界数据分布发生变化（数据漂移，data drift）时导致的模型性能下降
    3. 为了确保模型的源代码与其 ML 框架的最新版本保持兼容
    4. 为了在初始部署时验证所用训练集是否代表部署环境
    显示答案

    正确答案是 B。部署后，真实世界数据可能随时间变化（数据漂移、概念漂移）。在历史数据上训练的模型可能随着输入分布的偏移而变得不那么准确。监控关键性能指标使工程师能够及早发现性能下降，并在部署系统造成重大错误之前触发重新训练或模型更新。

    考察概念： Model Deployment、ML Workflow

    10. 本课程涵盖的完整 ML 工作流从数据获取开始，到模型部署结束。哪个说法最好地评估了这个流程早期和晚期阶段之间的关系？¶

    1. 模型训练阶段最关键；如果算法足够强大，早期阶段的错误影响微乎其微
    2. 部署独立于早期阶段；训练良好的模型可以在任何环境中部署，无需修改
    3. 每个阶段都依赖于所有前序阶段的质量；数据质量差或预处理不足会向前传播并降低最终模型性能
    4. 评估阶段可以识别和修复数据获取中引入的错误，而无需重新处理数据
    显示答案

    正确答案是 C。ML 工作流是一个流水线，每个阶段都建立在前一个阶段的基础上。不良的数据获取会产生不具代表性的数据；不充分的预处理会将噪声带入训练；不充分的评估可能会部署一个过拟合的模型。这种上游错误的传播被"垃圾进，垃圾出"（garbage in, garbage out）原则所捕获。无论算法多么强大，都无法弥补根本上有缺陷的数据。

    考察概念： ML Workflow
